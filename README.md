# Wah Babuji Wah!! — Premium Website Redesign Demo

This is a concept redesign prepared for a sales/demo presentation.

## Design direction
A cinematic, premium, food-first visual system:
- Black / warm cream / amber / deep red
- Editorial typography
- Large food photography
- Strong mobile CTAs
- Menu category filtering with JavaScript
- Google Maps directions
- Responsive mobile navigation

## Files
- index.html
- style.css
- script.js

## Important
This is NOT the restaurant's official website.

Before production:
1. Get written approval from the restaurant.
2. Replace all stock/placeholder images with approved restaurant photography.
3. Confirm the exact menu, prices, address, phone, hours and other business information.
4. Replace the concept logo/branding with the restaurant's approved assets.
5. Deploy only after the owner/client approves the final content.

The menu currently contains sample items and intentionally uses "₹—" instead of unverified prices.

## Suggested sales angle
Do not say the restaurant has no website. They already have an online site.

Pitch this as:
"modern redesign + stronger mobile experience + better food presentation + clearer customer journey."

Open `index.html` locally or deploy the folder to Vercel/Netlify for the demo.
